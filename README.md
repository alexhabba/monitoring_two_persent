# monitoring_two_persent

Бот для Bybit (USDT-перпетуалы, API V5). Следит за всеми открытыми позициями и,
когда **суммарная чистая прибыль** (с учётом комиссий и фандинга) достигает цели
(по умолчанию 2%), начинает **постепенно** закрывать позиции лимитными ордерами,
подстраивая размер под стакан, чтобы не двигать цену. Закрытие идёт, только пока
прогноз чистой прибыли по всему портфелю остаётся ≥ цели.

## Как считается прибыль
Для каждой позиции:

```
чистый PnL = (цена выхода − цена входа) × размер        (для шорта наоборот)
           + cumRealisedPnl                              (комиссия входа + фандинг + уже закрытые части)
           − комиссия выхода
```

* Цена выхода — консервативно: лонг по best bid, шорт по best ask, минус `SLIPPAGE_BUFFER_BPS`.
* Комиссия выхода — по **тейкер**-ставке вашего аккаунта (берётся из API), хотя ордера ставятся мейкером.
* Процент = сумма по всем позициям (+ зафиксированное уже закрытыми) / база.
  База: `PROFIT_BASE=equity` (капитал аккаунта) или `margin` (маржа, занятая позициями).
  Во время закрытия база замораживается.

## Как закрывает
* Ордер: `Limit`, `PostOnly`, `reduceOnly` — всегда мейкер и не может открыть/перевернуть позицию.
* Цена: лучшая цена своей стороны (лонг — best ask, шорт — best bid): встаём в очередь, стакан не съедаем.
* Размер куска = `BOOK_FRACTION` (10%) от ликвидности в пределах `BOOK_DEPTH_BPS` от лучшей цены,
  с учётом `qtyStep`/`minOrderQty`; «пыль» не оставляется.
* Не выставляет ордера при спреде шире `MAX_SPREAD_BPS`.
* Не исполнился за `ORDER_TIMEOUT_SEC` — отменяется, на следующем шаге всё пересчитывается по свежему стакану.
* За шаг — один кусок одной позиции (по кругу); перед каждым куском PnL пересчитывается.
  Упал ниже цели — закрытие приостанавливается.

## Запуск
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # впишите ключи
python main.py --once     # один проход: только показать PnL
python main.py            # цикл, по умолчанию DRY_RUN=true (ордера НЕ отправляются)
python main.py --live     # боевой режим
pytest                    # тесты
```

**Рекомендуемый порядок:** `BYBIT_TESTNET=true` → DRY_RUN на реальном аккаунте (сверьте
процент в логе с интерфейсом Bybit) → `--live` на малой позиции.

API-ключ: только права на ордера/позиции деривативов, **без права вывода**, желательно с привязкой к IP.

## Допущения — проверьте
1. «2%» — от капитала аккаунта (`equity`). Если нужно от маржи позиций — `PROFIT_BASE=margin`.
2. `cumRealisedPnl` по позиции содержит комиссию входа и накопленный фандинг. Сверьте с UI в DRY_RUN.
3. Рассчитано на режим Unified Trading Account и категорию `linear`.
4. Позиции, закрытые полностью во время сессии, учитываются по последней оценке перед исчезновением (приблизительно).

Не является финансовой рекомендацией; вы отвечаете за торговые решения и риски.
